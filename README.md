# PDR kalkulačka

Jednoduchý výpočtový formulář opravy důlků (PDR) podle ceníku.

## Jak otevřít

Dvojklikem otevřete soubor `index.html` v prohlížeči. Server ani Python není potřeba.

## Použití

1. Vyberte průměr důlků (20 / 30 / 40 mm).
2. Přidejte poškozené díly a počet důlků na každém dílu.
3. Výsledek se přepočítává průběžně. Tlačítko **Spočítat** výpočet spustí znovu.

Cena = součet ceníkových cen dílů + 2 % drobný materiál + demontáž (2 500 Kč do 50 000 Kč, 3 000 Kč nad 50 000 Kč) + 21 % DPH.
